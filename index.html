🧠 Weaver's Brain Maze+

Created by Kara Smith

Answer questions to escape the maze!

Maze Game

🎮 Use WASD or Arrow Keys • Answer questions to unlock doors • Reach the green exit!

Level: 1
Score: 0
Lives: 3

How I Built This Game

This game uses HTML, CSS, and JavaScript.

The maze is generated with a recursive backtracking algorithm.

Movement, scoring, and collisions are handled with grid-based logic.

Answering questions unlocks doors and teaches coding concepts.
